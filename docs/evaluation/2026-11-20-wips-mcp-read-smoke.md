# 2026-11-20 WIPS MCP 연결·읽기 기능 재확인 (외부 설명용 기술 상태)

- 날짜: **2026-11-20**. 장소/계정: 연결된 개인 ChatGPT ↔ 기존 WIPS MCP. **타 조직의 실제 계정·망·서비스 환경에서 검증한 결과가 아님**.
- 상태: `PERSONAL_WIPS_MCP_READ_PASS` / `CUSTOMER_ENV_INTEGRATION_NOT_TESTED` / `PRODUCTION_E2E_NOT_CLAIMED`.
- 목적: 기존 [WIPS MCP 카탈로그](../40-wips-mcp-capability-catalog.md)와 [AI 검색 A/B](2026-11-20-eval01-wips-ai-300char-ab.md)에 후속하여, 최신 세션에서 실제 읽기 전용 MCP가 정상 응답하는지 최소 호출로 확인.
- 공개 보안: 실제 검색원문, 검색된 문헌 번호/SKEY, 제목/요약/청구항/고객 자료·연락처·서비스 도메인/인증정보·내부 IP는 기록하지 않음. **일반 공개 기술 주제만 사용**.

## 실제 도구 확인

| 호출 | 최소 조건 | 실제 반환 | 판정 |
|---|---|---|---|
| `get_patent_search_onlyengine` | 공개 일반 주제 2조건 WINTELIPS Boolean AND, 요청 top2, `SKEY,XN_D,CC,KC_D,TIK,ABK,CLK` | `success=true`, 목록 **2건**, 두 문헌 모두 제목/요약/대표청구항 필드 있음 | **PASS** |
| `get_patent_ai_search` | 한국(KR) 공개 기술 서술 **388자**, `ctry=KR,targetCtry=KR,size=2` | `success=true`, 후보 **2건** | **PASS** |
| `get_patent_by_skey` | 위 일반 검색 반환 문헌 중 한 건의 식별자를 사용(공개 기록 금지) | `success=true`, 제목/요약/청구항 존재 | **PASS** |

- AI 유사검색의 **300자 이상**은 현재 사용자가 시험에서 택한 긴 설명 기준이며, provider 최소 길이 강제 조건 또는 특정 정확도 보증으로 단정하지 않는다.
- **위 3개는 실제 MCP 읽기 도구 호출 PASS**이다. 검색 결과가 고객 연구과제에 적합한지, 상대 고객의 계정에 WIPS 구독/권한이 있는지, 서비스 backend에서 직접 MCP 호출이 되는지까지 검증한 것은 아니다.
- 특허 공보 PDF 바이너리 직접 다운로드 도구는 현 연결의 카탈로그에서 별도 확인되지 않았으며, 공급자 별도 API/파일 제공 방식은 미검증.
- 기존 개인 NAS RAG PoC의 검색·AI 관련성 평가·기존 구매자료 재활용은 **이 WIPS 연결 확인과 별개**다. 고객 시스템에 NAS, pgvector, 원문 수집/영속 DB, 자율 Agent, 데이터 이전이 설치되었다고 주장하지 않는다.
- 이 확인은 WIPS MCP의 **기본 연결/조회 동작과 지원 가능성** 설명용이다. 신규 계약/라이선스/상용 운영 승인, 고객시스템 통합테스트 및 PDF 정식 확보는 별도 상태다.

## 외부 설명에서 사용할 수 있는 결론

> WIPS MCP의 기본 기술동작을 사전 검토했습니다. 개인 시험 환경에서 특허 검색식 조회, 자연어 기반 AI 유사특허 검색, 문헌 제목·요약·대표청구항 조회가 실제로 정상 응답했습니다. 실제 업무 시스템 연동과 운영 적용은 계정·접근권한·제공 범위 및 서비스 환경 검증이 필요한 별도 단계입니다.

**잔여(이 설명 기준):** 보고에 필요한 3개 읽기 경로의 실측은 완료. 고객 환경 접근과 계정 권한·공보 PDF·전체 앱 자동화·서비스 인수/비용 ROI는 **미실시/별도 검증**이다. 이 문서만으로 상용 제품 개발 완료·고객 인수 완료를 주장하지 않는다.
