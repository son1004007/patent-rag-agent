## 1. 왜 다시 검색했는가

장문 10문항 파일럿에서 Q04(형광 태양광 봉지재)와 Q06(난연 전해질)는 짧은 입력보다 직접 후보가 줄었다. Q05(저온 접합+습열)·Q08(SiC 전력반도체)는 장문에서도 핵심 특성을 놓쳤다. **300자 이상은 필요충분한 정확도 조건이 아니다.** 문장을 늘리는 대신 핵심 기술 목적·소재·핵심 청구 수단을 중심에 둔 A/B 변형을 만들고 다시 검색했다.

## 3. AI 최종 실행 규칙

1. **1차**: 공개 가능한 기술 설명 300자 이상, 핵심 재료/기술 목적/작용 원리/성능 요구를 분리. 부정·제외 항목을 자연어에 너무 많이 반복해 유사 검색을 오염시키지 않는다.
2. **2차(조건부)**: 1차의 `AI_DIRECT@3=0` 또는 서로 다른 기술군이 섞이면 **동일 연구 목적을 유지**하며 중심 원리·청구 특징만 바꾸어 300자 이상 A/B 재검색(각 최대3건). 이 과정은 실제 WIPS 호출 비용에 포함하고 결과별 버전을 기록한다.
3. **채점**: `get_patent_by_skey`의 요약·청구항에서 **필수 조건을 동시에** 확인해 0/1/2로 AI 판정한다. 추정 근거·빈 요약·권리상태 미검증이면 `HOLD`.
4. **중복**: 동일 문헌/공개등록/동족 출원은 독립 기술 발견수로 이중 계산 금지. 이 실험에서는 패밀리 전수검증하지 않았으므로 `FAMILY_UNVERIFIED`.
5. **보안**: 공개 연구질문만 사용, NAS 권한/신규 문헌 ingestion/PDF/DB/타 서비스 변경 없음.
