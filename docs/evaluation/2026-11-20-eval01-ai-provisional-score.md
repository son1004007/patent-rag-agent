# EVAL-01 — AI 예비 관련성 채점 (10문항, 각 출처 Top3)

- 날짜: 2026-11-20
- 상태: **AI_PROVISIONAL_SCORED (10/10)** / **HUMAN_GOLD_LABEL_NOT_RUN** / **FORMAL_DECISION_INCONCLUSIVE**
- 평가자: ChatGPT GPT-6 (단일 AI 평가; 별도 사람·전문가 검수 없음)
- 대상: [10문항 read-only 실측 기준선](2026-11-20-eval01-live-retrieval-baseline.md)과 같은 공개 연구질문/검색식의 **새 읽기 조회 결과**. 이전 응답 원본이 영구 보존되지 않아 **최초 실험 결과와 바이트·순위가 완전히 동일한지는 미검증**.
- 결정 정본: [DECISION-01](../44-mvp-evaluation-decision-criteria.md), [EVAL-01 계획](../45-search-quality-comparison-plan.md), [평가 인덱스](INDEX.md).
- **이 파일은 공개 저장소이므로 실제 특허 제목·SKEY·공보번호·문헌ID·원문·실제 검색식·응답/해시·접속정보를 저장하지 않는다.** 표는 실문헌 식별자 없는 case별 익명 집계.

## 1. AI 채점 규칙

- **2점(직접 관련)**: 질문에서 요구한 기술 대상과 핵심 특성이 요약·대표 청구항 또는 NAS 상세 근거에 **명시적으로 대응**하는 경우. 실제 물성 검증/권리 유효성 인정과는 별개.
- **1점(간접 관련)**: 같은 기술군/기초 재료·공정이나 핵심 속성·성능·사용처 중 일부만 일치/미입증.
- **0점(무관)**: 질문의 연구 목적/필수 소재·속성과 직접적인 연결이 확인되지 않는 경우.
- 질문마다 WIPS 상위3, NAS 상위3을 각각 채점하고 `AI_P@3=2점 후보 수/3` 계산. **인간 gold label 기반의 공식 P@3와 구분**. 결과가 없거나 근거가 부족한 사례를 억지 추천하지 않고 0 또는 1로 보수적 판정.
- NAS 기존 private read-only 근거를 필요한 범위에서 `get_patent` 추가 확인, WIPS 국문 요약+대표청구항을 근거로 1차 평가. 전체 전문·도면·청구항 전체 비교 및 외부 독립 감사는 미수행.
- **평가 편향**: AI가 검색 후보를 다시 직접 보고 자기 채점을 수행했기 때문에 블라인드/독립 평가가 아니다. 상위3 정렬/검색식 차이, NAS 6문헌 범위, WIPS 더 넓은 corpus가 교란된다.

## 3. 분리 분석

| 지표 | WIPS | NAS | 주의 |
|---|---:|---:|---|
| 전체 직접(2점) | 1/30 = 3.3% | 5/30 = 16.7% | **AI 자체 채점**; 독립 지표 아님 |
| IN 5질의 직접 | 1/15 = 6.7% | 5/15 = 33.3% | NAS의 **사전 보유 분야**이므로 공정한 범용 성능 비교가 아님 |
| OUT 5질의 직접 | 0/15 | 0/15 | NAS가 반환한 15개는 모두 직접 관련 없다고 잠정 판정; 시스템 자체는 근거 부족일 때 HOLD 해야 함 |
| 질문별 NAS 추가 직접 | Q01, Q03, Q04 총 **3문항** | WIPS Top3에 없는 AI상 직접 후보 | 같은 기술의 공개·등록 중복 가능성, WIPS 검색식·정렬 비동등 |
| family 중복 | 별도 미확인 | Q04 NAS 직접 관련 2개는 동일 발명 계열 가능 | Q04를 **독립 기술 2개**로 집계 금지 |

**중요:** WIPS 검색식은 일부 OR 키워드 조합 때문에 수천~수만 건으로 넓어졌고, 검색 결과 정렬을 검증하지 않았다. 따라서 **"WIPS의 정확도가 3.3%" 또는 "NAS가 WIPS보다 5배 정확"이라고 주장하는 것은 잘못**이다. 출처에 따라 후보를 더 많이 검토한 통합(최대6)도 별도 순위가 없으므로 `P@3_C` 산출 금지. 본 채점은 최초 EVAL-01 추출된 도구 응답을 완전 재현한 결과가 아닌 추가 조회에 기반한 AI 예비 평가다.

## 4. 근거 안전성과 오류 상태

- WIPS 국문 요약·대표청구항, NAS excerpt 및 일부 개별 `get_patent`의 abstract/claim/detailed section을 대조한 **주제·속성 일치성**만 평가했다. 출처 해시의 존재는 실제 원문 문장의 진위나 요약 정확성을 검증한 것이 아니다.
- 직접 후보 중 하나의 **공개/등록 문헌 계열 중복**이 의심되므로 문헌 단위 `AI_P@3`을 발명 단위 신규 기술수로 전환하지 않는다. IN 범위 내 성능뿐 아니라 OUT에서 비관련 특허가 계속 순위에 올라오는 **비보유 자료의 검색 한계**를 드러낸다.
- **본 10문항에 대한 공식 판단은 `INCONCLUSIVE` 유지**: 연구자·독립인 사람의 0/1/2 gold label 없음, 관련 근거의 원문 전수 검증 없음, 검색식/정렬 편향 통제 없음, WIPS API 대 MCP 품질 비교 없음.
- **추가 실험 권고 우선순위**: (1) WIPS 검색식을 의도에 맞게 정밀화하고 동등한 결과 예산에서 재비교, (2) 기존 원문과 의미상 같은 공개/등록 family 판정, (3) 계약 허용 비공개 평가 레코드와 사람 검토 확보, (4) 그 후 공식 P@3·근거 정확도·GO/LIMITED_GO/NO-GO 결정, (5) EVAL-02 반복 효익.
- 회사·고객 데이터나 NAS/서지/벡터/PDF에 새로 쓰기, MyFolder 사용, 재시작·외부 공개·권한 확대 없음. **실제 DB row/fingerprint 불변 검사는 별도 NOT RUN**.

**판정 요약:** `AI_PRELIMINARY_P3_WIPS=1/30`, `AI_PRELIMINARY_P3_NAS=5/30`, `HUMAN_GOLD=0/10`, `OFFICIAL_EVAL01=INCONCLUSIVE`.
