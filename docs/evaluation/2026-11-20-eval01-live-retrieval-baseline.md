## 1. 질문 10개와 사전 평가군

기존 개인 NAS 원문이 주로 태양광·봉지재 분야임을 **사전 읽기 전용 probe**로 확인했다. 공개·일반 기술 질문 10개의 주제와 WIPS 검색식, NAS 자연어 표현을 각 도구 호출 전에 정했다. **필수 속성·제외 조건에 대한 독립적인 사람용 채점 루브릭은 아직 확정하지 않았다**. 상세 검색식을 GitHub에 저장하지 않았으므로 완전 재현에는 공급자 보존 권리 확인 후 별도 비공개 입력 원장이 필요하다. 아래에는 민감 원문·WIPS 검색식을 쓰지 않고 **비식별 case ID + 일반 기술 분야**만 표기한다.

- IN Q01~Q05: 기존 원문 문헌에서 관련 기술을 찾을 여지가 있는 태양광 봉지재/밀봉/페로브스카이트/POE/형광·접합 주제.
- OUT Q06~Q10: 기존 원문6건의 직접 기술 범위 밖인 리튬이온 난연 전해질/수처리 막/SiC 전력반도체/전력 케이블 도체/의료용 봉합사 주제.
- 자료 스냅샷 기준: 과거 운영 실측 **83 metadata / 6 fulltext / 10 sections / 417 vector chunks / 0 PDF**. 이번 실행에서 DB 직접 row-count, fingerprint, 파일 불변성을 별도 재검증한 것은 **NOT RUN**. NAS 검색이 기존 private corpus임은 응답의 `scope`로 확인.
- WIPS 검색 결과는 **상위3개만** 반환 받았고 요약 ABK/대표청구항 CLK 필드가 채워졌는지만 기계적으로 확인했다. 새로운 원문·권리정보 정확도 검증은 하지 않았다.

- ID 중복은 **국가 + 공보번호 + 공보종류**를 대문자/영숫자로 정규화한 뒤 exact 비교. 동일 발명 패밀리·의미상 동일 기술까지 통합한 수치가 아님. **Q02 2건의 정확한 같은 문헌 키가 재조회/검산에서 확인됨.**
- 유효한 최종 검색 목록이 있다는 뜻이지 유효한 특허 추천이나 정답이라는 뜻은 아님. **OUT 5개 질문에서도 NAS는 3개씩 총15개를 반환**하므로 벡터 유사도만 보고 추천하면 범위 밖 오추천 위험이 있음. 직접 관련성은 사람 검증 전 UNKNOWN.
- WIPS 초기 검색 시 Q04/Q06/Q09의 `success`가 false/불완전 반환(상세 원인은 비표시). **각 1회 bounded retry 후 success=true**. 중복/근거 count를 검산하기 위한 추가 읽기 조회는 수행했으나, 재시도 비용과 횟수는 품질 측정의 독립 변수가 될 수 있다.
- 호출 흐름은 초기 별도 검색식 probe 1회, 본 10문항 검색 각 1회, 실패3 재시도, 3문항 dedup 검산. **WIPS 검색 도구 호출 총17회**(일부 중복 측정 포함), 본 10문항의 최종 성공은 **10개**. NAS는 사전 probe 및 검산·상세 증거 호출을 추가로 수행했으므로 '건당1회 최적 비용/지연'으로 취급할 수 없다.
- 다른 limit을 탐색한 NAS 호출 한 건은 `Invalid query or limit`로 거부되었고 이후 계획된 `limit=3`으로 진행. 사설 자료 쓰기는 없음.

## 3. 근거와 품질이 실제 검증된 범위

**증거 확인 단계 주의:** 반환값에 text·source hash가 있다고 해서 근거 주장이 진실이거나 원문 전체가 검증되었다는 뜻이 아니다. 사전 probe 외 추가 fulltext 저장 없이 이미 보유한 6개 문헌의 일부를 읽었음. 사람 라벨 없이 기계적 관련성만으로 P@3 계산/GO 확정하면 계약·품질 요구 위반이다.

## 4. 미완료·실패·다음 실행

1. **가장 큰 잔여:** 비공개 원응답/문헌 식별자·발췌를 사용자 또는 합법적인 검토자가 검토하여 각 후보 0/1/2, 출처/청구항 일치·HOLD 적절성을 채점. 이번 채팅의 원응답은 추후 자동 재접근 보장되지 않음. provider 원응답의 **지속 저장 권한 확인 전에는 GitHub나 신규 파일에 자동 보관하지 않음**.
2. 사람 확인 전 EVAL-01의 최종 정확도/근거 성공률/GO-NO_GO 판단은 **INCONCLUSIVE / HUMAN_LABEL_PENDING**. 10문항 검색이 성공한 것은 **Q2 retrieval stage PASS**이지 EVAL-01 완료가 아니다.
3. OUT 결과의 NAS 후보가 다른 분야로부터 유사하게 검색되는 현상은 **coverage mismatch**로 분리하고, 기존 데이터만으로 확정 추천하지 않도록 HOLD. WIPS 대용량 반환 `total_count`는 검색식의 넓이만 의미하며 직접 관련 결과 수가 아니다.
4. 추후 정상 승인 범위에서 **WIPS/NAS 후보 식별자와 근거를 비공개 보관할 합법적인 실행 위치**를 정한 후 블라인드 사용자 관련성 채점, deterministic score, 사용자 #31 인수 → EVAL-02 반복 효익 순서. 기존 운영 서비스·데이터 삭제/권한 확대/재시작은 불필요.
5. 실제 WIPS 3개 초기 실패는 재현 원인을 확인하지 못함. 자동 무한 재시도 금지, 운영 검색 실패율/재호출 정책은 별도 지표로 추적.

**최종 판정:** `RETRIEVAL_AND_EXCERPT_AVAILABILITY=PASS`, `HUMAN_RELEVANCE_AND_CITATION_ACCURACY=NOT_RUN`, `EVAL01_FINAL=INCONCLUSIVE`. 기존 기술사의 데이터·공용 서비스 변경 없음.
