# 요구사항 — 초안

| ID | 요구 | 인수 기준 |
|---|---|---|
| R01 | 짧은 자연어 질문 | 원문 보존 및 분야·목적별 검색 |
| R02 | 자동 확장 | 300~500자 실험 질의 및 수정 가능; 없는 제약/수치 창작 금지 |
| R03 | 다중 검색 | 원문 AI/확장 AI/키워드/내부 검색 선택 및 결합 |
| R04 | 근거 기반 추천 | 문헌번호·요약·근거·출처·조회일·불확실성 |
| R05 | 자동 수집 | 권한 있는 신규 자료만, 중복 제거·재시도 안전 |
| R06 | 자체 RAG | 텍스트+벡터 검색, 자료 범위/최신성 명시 |
| R07 | 사용자 관리 | 개별 인증, 본인 profile, 권한·사용량 |
| R08 | 비용 제어 | 요청별 공급자 호출/토큰/지연/추정비용·budget |
| R09 | 외부 HTTPS | IP 제한은 외부 장비, DB 직접 공개 금지 |
| R10 | 재사용·문서 | 공급자/분야 설정 분리, 모든 문서 인덱스 |

비범위: 전수 자료 덤프, 검증되지 않은 물성 보장, 법률적 특허 침해 판정, 네트워크 장비 자동 변경. MVP 한국 특허·합성 자료 우선.
