# MVP-06 — 개인 ChatGPT 실제 사용 시험 및 사용자 인수
2026-11-19 | 읽기 기능 시험 PASS, 설명서 작성, 사용자 평가 대기. 대상: 개인 사용자·개발자.

## 직전 대화 실제 실행 기록
일반 공개 연구 질문: **태양광 모듈 봉지재의 수분 차단과 저온 공정**. 기존 내습성·광투과율 사례와 다른 특성 조건을 선택했다. 직전 ChatGPT 대화에서 WIPS 키워드 검색 1회, NAS RAG search_patents 1회 및 반환 ID별 get_patent 3회 실제 순차 호출. 현재 커밋 8f94da91a5fc59451c2e52b260201a87fe0aa2ba의 [비교 모듈](../poc/mvp04_candidate_compare.mjs)을 격리 JS 실행으로 적용. 실제 자료·식별자·개별 해시·본문 미기록.

| 항목 | 실제 결과 |
|---|---:|
| NAS 검색 | 3 |
| WIPS 검색 | 3 |
| NAS 상세 조회 found/ID 일치 | 3/3 |
| 중복 | 1 |
| 고유 후보 | 5 |
| 수집된 근거(모듈 집계) | 18 |
| HOLD | 4 |
| EXCLUDE | 1 |
| REVIEW_CANDIDATE | 0 |

수분 차단 기준어(수분, 방습, 내습, 습기, 수증기)와 저온 공정 기준어(저온, 저온경화, 저온 경화, 저온 공정)를 검사하고 제목의 재활용/폐모듈 등을 제외했다. 두 특성 모두 확인된 검토 후보가 없으므로 추천0은 근거 부족에 따른 올바른 보류 결과다. 검색 적중률, 실제 성능, 법적 유효성을 증명한 것은 아니다. 별도 운영 자동 Agent 및 신규 적재는 실행하지 않았다. 사용자에게는 집계 및 복사할 프롬프트를 전달했다. 이번 문서 작성 차례에서 같은 실제 WIPS 요청을 반복 호출하지 않고 직전 대화의 실행 결과를 기록한다.
